## 한눈에 보기

PuTTY는 SSH 클라이언트이고, 터널은 그 연결 위의 포트 전달이에요. Connection의 SSH, Tunnels에서 소스 포트와 대상을 넣고 세션에 저장해요. 로컬은 내 PC가 듣고, 원격은 서버가 듣고, 동적은 SOCKS 프록시예요. 저장 뒤에 세션을 열어 이벤트 로그에 포워딩 거절이 있는지를 봐요.

## SSH 터널링과 PuTTY의 역할

OpenSSH의 옵션을 PuTTY 화면 항목으로 옮긴 것이라고 보면 돼요. 호스트 이름과 포트, 사용자, 키는 세션과 인증 화면에 두고, 터널만 Tunnels에 추가해요. 추가 버튼을 누르기 전에 방향을 고르지 않으면 의도와 다른 종류로 들어갈 수 있어요. 설정 후 세션 저장을 빼먹으면 다음 접속에 터널이 없어요.

## 로컬·원격·동적 포워딩 비교

표는 듣는 위치와 대표 용도를 나눈 거예요. 로컬은 원격 내부의 데이터베이스처럼 대상이 하나일 때, 원격은 서버 쪽에서 내 PC 서비스로 들어올 때, 동적은 여러 대상을 프록시로 보낼 때예요. 소스 포트가 내 PC에서 이미 쓰이면 터널이 안 열려요.

| 구분 | 연결 방향 | 대표 사용 상황 | PuTTY 설정 핵심 |
|---|---|---|---|
| 로컬 포워딩 | 내 PC의 로컬 포트에서 SSH 서버 너머 대상으로 연결 | 사내 데이터베이스나 내부 관리 화면에 내 PC에서 접근 | Source port에 로컬 포트, Destination에 대상 호스트와 포트, Local 선택 |
| 원격 포워딩 | SSH 서버의 포트에서 내 PC 또는 내가 지정한 대상으로 연결 | 외부에서 서버를 거쳐 내 쪽 테스트 서비스에 접근 | Source port에 원격 포트, Destination에 로컬 대상, Remote 선택 |
| 동적 포워딩 | 로컬 포트를 SOCKS 프록시로 열고 목적지는 클라이언트가 결정 | 여러 목적지를 하나의 프록시 설정으로 유연하게 접근 | Source port에 로컬 프록시 포트, Dynamic 선택 |

## PuTTY로 로컬 포워딩 설정하는 단계

세션에 서버 주소를 넣고, SSH를 선택한 뒤 Tunnels로 가요. 소스 포트에 내 PC에서 들을 포트를 적고, 대상에는 SSH 서버가 보는 호스트와 포트를 적어요. 로컬을 고르고 추가한 다음, 세션 화면으로 돌아와 저장하고 엽니다. 열린 뒤에는 내 PC의 그 포트로 접속해 대상 서비스가 응답하는지 봐요. 이벤트 로그에 포워딩 실패가 있으면 포트 충돌부터 확인해요.

## PuTTY로 원격 포워딩과 동적 포워딩 설정하기

원격은 방향을 원격으로 두고, 소스 포트는 서버가 들을 포트, 대상은 내 PC의 서비스예요. 다른 장비에서 서버 포트로 들어오게 하려면 서버 sshd 설정이 허용해야 해요. 동적은 대상 호스트 없이 소스 포트만 두고 동적 포워딩으로 추가해요. 브라우저 프록시를 그 포트의 SOCKS로 맞춰야 트래픽이 들어가요.

## 상황별 선택 기준

관리용으로 데이터베이스 포트만 열 때는 로컬 포워딩과 세션 저장이 맞아요. 잠깐 데모를 외부에 보여 줄 때만 원격 포워딩을 쓰고 세션을 닫아요. 여러 내부 사이트를 볼 때는 동적 포워딩과 브라우저 프록시예요. 항상 켜 둘 터널이면 저장된 세션과 함께, 창이 꺼져도 유지할 방법이 따로 필요한지 검토해요.

## 주의할 점

PuTTY 창을 닫으면 터널도 끊겨요. 원격 포워딩을 넓게 열면 서버에 접속할 수 있는 사람에게 내 서비스가 보여요. 호스트 키 경고를 습관처럼 넘기지 마세요. 개인 키는 인증 도구에만 두고 공유 폴더에 두지 않아요. 회사 정책이 포워딩을 금지하면 클라이언트 설정만으로 우회하지 마세요.

## 자주 묻는 질문

창을 닫았을 때, 방향, 동적 포워딩, 원격이 안 될 때가 핵심이에요.

### PuTTY 터널은 PuTTY 창을 닫아도 유지되나요?

아니요. 그 세션의 연결이 터널을 붙들고 있어서, 창을 닫으면 포워딩도 끝나요. 유지하려면 세션을 열어 둔 채 두거나, 별도 유지 방법을 써야 해요.

### 로컬 포워딩과 원격 포워딩은 무엇이 다른가요?

로컬은 내 PC가 포트를 듣고 서버가 대상에 접속해요. 원격은 서버가 포트를 듣고 내 PC가 대상에 접속해요. Tunnels에서 고른 방향이 이 차이를 만들어요.

### 동적 포워딩은 언제 쓰나요?

대상이 여러 개라 포트마다 규칙을 만들기 어려울 때 써요. 애플리케이션이 SOCKS 프록시를 지원해야 해요. 지원하지 않는 프로그램은 터널을 타지 않아요.

### 원격 포워딩이 안 될 때 무엇을 확인해야 하나요?

PuTTY에서 추가와 세션 저장을 했는지, 서버가 그 포트를 듣는지, sshd가 원격 포워딩을 허용하는지를 봐요. 이벤트 로그의 거절 문구가 클라이언트 문제인지 서버 거부인지 갈라 줘요.
