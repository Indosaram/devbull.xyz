## 한눈에 보기

aws-native는 CloudFormation 리소스 스키마에 가까운 이름을 쓰고, 클래식 aws는 Pulumi가 오래 다듬은 스키마예요. 신규 리소스를 Cloud Control 기준으로 따라가려면 native를 검토해요. 기존 코드와 예제가 많으면 클래식이 이식이 쉬워요. npm 설치만으로 배포되지는 않고 CLI와 자격 증명, 스택이 필요해요.

## 비교 표: AWS Native와 클래식 공급자

표는 패키지 성격, 스키마, 속성 이름, 지원 범위, 적합한 경우를 나눈 거예요. native는 Cloud Control이 지원하는 리소스 중심이고, 클래식은 예제와 부가 기능이 넓어요. 혼용할 때는 같은 자원을 양쪽이 소유하지 않게 나눠요.

| 항목 | @pulumi/aws-native | @pulumi/aws |
|---|---|---|
| 패키지 성격 | AWS Cloud Control API 기반 공급자 | AWS API를 Pulumi 리소스로 감싼 클래식 공급자 |
| 리소스 스키마 | CloudFormation 리소스 스키마와 연결 | Pulumi가 관리하는 클래식 스키마 |
| 속성 이름 | CloudFormation 스키마에 가까운 이름 | 클래식 공급자 고유 이름 |
| 지원 범위 | Cloud Control API가 지원하는 리소스 중심 | 넓은 역사와 예제, 부가 기능 |
| 적합한 경우 | CloudFormation 정합성, 신규 리소스 추적 | 기존 코드, 풍부한 예제, 마이그레이션 |
| 주의 | 리소스별 지원 여부 확인 | AWS Native와 혼용 시 소유권 분리 |

## 단계별 방법: npm 설치부터 배포까지

프로젝트를 만들고 @pulumi/aws-native를 설치해요. 리소스 이름이 클래식과 다르니 레지스트리 문서의 그 리소스 페이지를 보고 작성해요. 자격 증명과 리전을 스택 설정으로 드러내요. 미리보기에서 생성과 교체를 읽은 뒤 업을 실행해요. 지원되지 않는 리소스는 클래식으로 보완해요.

```
npm install @pulumi/aws-native
```

```
import * as awsNative from "@pulumi/aws-native";

const bucket = new awsNative.s3.Bucket("site-assets", {
    bucketName: "example-site-assets",
});

export const bucketName = bucket.bucketName;
```

## 상황별 선택

CloudFormation 정의와 이름을 맞추고 싶으면 native를 검토해요. 팀이 이미 aws 패키지 예제로 운영하면 클래식을 유지하고, 없는 신규 리소스만 native를 시험해요. 한 리소스를 두 공급자로 동시에 관리하지 마세요. 버전은 잠금 파일로 고정해요.

## 주의할 점

속성 이름을 클래식 예제에서 그대로 가져오면 타입 오류가 나요. Cloud Control 미지원 리소스는 설치가 돼도 정의할 수 없어요. 업그레이드는 스키마 변경이 있을 수 있으니 시험 스택 미리보기가 먼저예요. 상태 백엔드를 로컬에만 두면 협업이 깨져요.

## 자주 묻는 질문

패키지 이름, 혼용, 지원 범위, 설치만으로 배포되는지예요.

### pulumi aws native npm 패키지 이름은 무엇인가요?

npm 패키지 이름은 @pulumi/aws-native예요. 클래식은 @pulumi/aws예요. import 경로도 문서의 그 버전을 따라요.

### 기존 @pulumi/aws와 함께 사용할 수 있나요?

한 프로그램에 같이 둘 수 있어요. 같은 자원을 두 공급자가 만들게 하면 충돌해요. 소유를 리소스 단위로 나누세요.

### AWS Native가 모든 AWS 리소스를 지원하나요?

아니요. Cloud Control API가 지원하는 범위가 중심이에요. 없는 리소스는 클래식이나 다른 방법을 문서에서 봐요. 지원 여부는 레지스트리의 리소스 목록이 기준이에요.

### npm 설치만 하면 바로 배포할 수 있나요?

아니에요. Pulumi CLI, 스택, AWS 자격 증명이 있어야 업이 돼요. 설치 뒤 미리보기로 자격 증명과 리전이 맞는지 먼저 봐요.
