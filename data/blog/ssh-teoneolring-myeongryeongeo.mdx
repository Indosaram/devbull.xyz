SSH 터널링 명령어는 로컬 포트를 원격 서비스에 잇거나, 원격 포트를 내 쪽에 잇거나, 동적 프록시로 여러 대상을 우회할 때 써요. 옵션 이름이 비슷해서 L과 R을 바꾸면 접속 방향이 반대로 열려요. 세션을 명령 없이 유지하려면 관련 옵션을 같이 둬요. 아래는 세 방식의 명령 형태와 고르는 기준이에요.

## 한눈에 보기

터널은 SSH 연결 위에 포트 전달을 얹는 거예요. 로컬 포워딩은 내 컴퓨터가 듣고, 원격 포워딩은 SSH 서버가 들어요. 동적 포워딩은 특정 대상 하나 대신 SOCKS 프록시처럼 여러 대상을 SSH 서버 경유로 보내요. 공통으로 접속 계정, 키, 서버 설정에서 포워딩 허용 여부를 확인해야 터널이 열려요.

## 포워딩 방식 비교

표는 옵션, 누가 포트를 듣는지, 누가 최종 대상에 접속하는지를 나눈 거예요. 로컬 포워딩은 내 PC에서 원격 내부 서비스에 닿을 때, 원격 포워딩은 원격에서 내 쪽 서비스에 닿게 할 때 써요. 동적 포워딩은 브라우저나 도구의 프록시 설정과 함께 써요. 방향을 표의 듣는 위치 열로 다시 확인한 뒤 명령을 실행하면 실수가 줄어요.

| 방식 | 명령 옵션 | 연결이 시작되는 쪽 | 주로 쓰는 상황 |
| --- | --- | --- | --- |
| 로컬 포워딩 | `-L` | 내 컴퓨터가 수신 | 내 PC에서 원격 서버 뒤의 데이터베이스나 웹 서비스에 접근 |
| 원격 포워딩 | `-R` | SSH 서버가 수신 | 외부에서 접근하기 어려운 내 쪽 서비스를 SSH 서버를 통해 노출 |
| 동적 포워딩 | `-D` | 내 컴퓨터가 SOCKS 프록시로 수신 | 여러 목적지에 접근해야 하는 브라우저나 도구의 프록시 설정 |

## 단계별로 실행하기

먼저 대상 호스트와 포트가 SSH 서버에서 보이는지, 내 컴퓨터에서만 보이는지를 정해요. 그다음 아래 방식 중 하나를 고르고, 이미 쓰이지 않는 로컬 포트를 골라요.

### 로컬 포워딩으로 원격 서비스 접근

내 포트, 대상 호스트, 대상 포트를 로컬 포워딩 옵션에 넣고 SSH 서버로 접속해요. 대상 호스트는 SSH 서버가 보는 이름이에요. 내 PC의 localhost가 아니에요. 브라우저나 클라이언트는 내 포트로 접속하면 터널을 타고 들어가요.

### 원격 포워딩으로 내 쪽 서비스 노출

원격 포워딩은 SSH 서버 쪽 포트를 내 컴퓨터의 서비스로 연결해요. 서버 설정이 원격 포워딩을 막으면 명령은 떠도 바깥에서 안 열려요. 다른 장비에서도 접속하게 하려면 바인딩 주소와 서버의 GatewayPorts 관련 설정을 문서 기준으로 봐요. 불필요한 노출은 피해요.

### 동적 포워딩으로 SOCKS 프록시 만들기

동적 포워딩 옵션에 내 포트를 지정하면 그 포트가 SOCKS 프록시가 돼요. 애플리케이션이 프록시를 쓰도록 설정해야 트래픽이 터널로 들어가요. 시스템 전체 VPN과 같지 않아요. 프록시를 모르는 프로그램은 그대로 직접 나가요.

### 함께 쓰는 공통 옵션

원격 명령을 실행하지 않으려면 N 옵션, 백그라운드로 내려면 f 옵션을 같이 써요. 연결이 끊기면 알아서 다시 붙지는 않으니, 필요하면 설정 파일의 유지 옵션이나 별도 감시 도구를 검토해요. 키와 사용자를 반복해서 치면 ssh_config에 호스트 별칭으로 모아 두는 편이 안전해요.

## 상황별 선택

데이터베이스처럼 대상이 하나면 로컬 포워딩이 맞아요. 외부에서 내 개발 서버를 잠깐 보여 줄 때만 원격 포워딩을 쓰고, 끝나면 세션을 끊어요. 여러 호스트를 같은 경유로 봐야 하면 동적 포워딩이에요. 상시 네트워크 경로가 필요하면 터널보다 정식 VPN이나 배스천 정책을 검토해요.

## 주의할 점

터널이 살아 있는 동안 그 포트는 로컬 권한을 가진 프로세스가 쓸 수 있어요. 신뢰하지 않는 계정과 포트를 공유하지 마세요. 원격 포워딩을 모든 인터페이스에 열면 의도보다 넓게 노출돼요. known_hosts 확인을 끄면 중간자 위험을 가리게 되니, 처음 지문은 확인해요. 서버가 포워딩을 제한하면 클라이언트 옵션만으로는 안 열려요.

## 자주 묻는 질문

옵션 방향과 백그라운드 유지, VPN과의 차이를 자주 물어요.

### ssh 터널링 명령어에서 `-L`과 `-R`은 무엇이 다른가요?

L 옵션은 내 컴퓨터가 포트를 듣고 SSH 서버가 대상에 접속해요. R 옵션은 SSH 서버가 포트를 듣고 내 컴퓨터가 대상에 접속해요. 누가 듣는지가 반대예요.

### `-N`과 `-f`는 언제 함께 쓰나요?

셸을 열지 않고 터널만 유지할 때 N 옵션을 쓰고, 그 세션을 백그라운드로 보낼 때 f 옵션을 같이 써요. 포그라운드에서 오류를 본 뒤에 백그라운드로 내리는 편이 원인 파악에 좋아요.

### 동적 포워딩은 VPN과 같은 역할을 하나요?

아니에요. 프록시 설정을 쓰는 프로그램만 SSH 서버를 경유해요. 시스템 라우팅 전체를 바꾸지는 않아요. 모든 트래픽을 보내야 하면 별도 구성이 필요해요.
