GRUB_TIMEOUT을 0으로 두면 부팅 메뉴에서 기다리지 않고 기본 항목으로 바로 들어가요. 메뉴를 숨기는 스타일 설정과는 역할이 달라요. 기본 파일만 고치고 설정을 다시 생성하지 않으면 실제 부팅은 그대로예요. 아래는 값이 하는 일, 반영 절차, 메뉴에 다시 들어가는 방법이에요.

## 한눈에 보기

대기 없는 부팅은 /etc/default/grub의 GRUB_TIMEOUT과, 생성 결과인 grub.cfg의 timeout이 같이 맞아야 해요. 0은 즉시 기본 항목으로 간다는 설정 값이에요. 메뉴를 숨길지는 GRUB_TIMEOUT_STYLE이 따로 정해요. 생성 명령을 빼먹으면 화면이 안 바뀌어요.

## GRUB 타임아웃 값이 하는 일

표는 GRUB_TIMEOUT, 스타일, 기본 항목, 생성된 timeout이 어디에 있는지를 나눈 거예요. 기본 파일의 0은 생성 뒤에야 부트로더가 읽어요. hidden은 메뉴를 감추고, menu는 메뉴를 보여 주는 쪽이에요. 기본 항목이 의도와 다르면 0으로 둬도 잘못된 커널로 들어가요.

| 항목 | 설정 위치 | 값 예시 | 실제 동작 |
| --- | --- | --- | --- |
| GRUB_TIMEOUT | /etc/default/grub | 0 | 기본 항목으로 즉시 진입 |
| GRUB_TIMEOUT_STYLE | /etc/default/grub | hidden | 메뉴를 숨기고 필요할 때만 노출 |
| GRUB_TIMEOUT_STYLE | /etc/default/grub | menu | 메뉴를 표시하는 방식 유지 |
| GRUB_DEFAULT | /etc/default/grub | 0 | 목록의 첫 항목을 기본으로 선택 |
| timeout | /boot/grub/grub.cfg | 0 | 생성 결과에 반영된 실제 값 |

## 설정 파일과 반영 절차

/etc/default/grub에서 GRUB_TIMEOUT을 0으로 두고, 필요하면 스타일을 정해요. 배포판의 생성 명령으로 grub.cfg를 다시 만들어요. 생성된 파일에 timeout이 반영됐는지 본 뒤에 재부팅해요. 클라우드 이미지면 그 이미지가 생성 명령을 다른 경로로 쓰는지 배포판 문서를 봐요.

## 상황별 선택

개인 데스크탑에서 메뉴가 거슬리면 0과 hidden을 같이 검토해요. 커널을 자주 바꾸면 0은 복구 진입을 어렵게 하니 짧은 대기나 메뉴 유지를 검토해요. 서버는 콘솔 접근이 어려우면 0으로 두기 전에 복구 경로를 확보해요. 듀얼 부팅은 기본 항목을 먼저 고정한 뒤 대기를 줄여요.

## 주의할 점과 복구

생성 없이 재부팅하면 예전 메뉴가 남아요. 0이면 키를 눌러 메뉴에 들어갈 시간이 거의 없어요. 스타일이 hidden이면 배포판이 안내하는 키로 메뉴를 부르는 방법을 미리 알아 두세요. 부팅이 깨지면 라이브 환경에서 기본 파일을 되돌리고 다시 생성해야 할 수 있어요. 클라우드 이미지는 시리얼 콘솔로 메뉴에 들어갈 수 있는지 먼저 봐요.

## 자주 묻는 질문

0과 hidden의 차이, 메뉴 진입, 반영이 안 될 때, 서버에서의 사용이 반복돼요.

### GRUB_TIMEOUT=0과 GRUB_TIMEOUT_STYLE=hidden은 무엇이 다른가요?

0은 대기 없이 기본 항목으로 들어간다는 값이에요. hidden은 메뉴를 숨기는 표시 방식이에요. 둘을 같이 쓰면 메뉴가 안 보이고 바로 부팅하는 쪽에 가까워요.

### 타임아웃을 0으로 두면 메뉴에 어떻게 들어가나요?

대기 시간이 없어서 보통의 타이밍으로는 메뉴가 안 잡혀요. 배포판이 안내하는 시프트나 이스케이프 같은 키를 부팅 직전에 쓰는 방법이 있어요. 복구가 필요하면 대기 값을 다시 주고 설정을 생성해요.

### 설정을 바꿨는데 부팅 화면이 그대로입니다.

기본 파일만 고치고 생성 명령을 안 돌린 경우가 많아요. grub.cfg의 timeout이 아직 예전 값인지 봐요. 다른 부트로더가 먼저 뜨는 환경이면 GRUB 설정이 화면에 안 나와요.

### 서버·클라우드 이미지에서도 0으로 두어도 되나요?

콘솔로 다른 커널을 고를 일이 없으면 쓸 수 있어요. 복구 콘솔이 없으면 0은 진입을 막아 위험해요. 이미지 문서의 부트로더 경로를 확인한 뒤 적용해요.
