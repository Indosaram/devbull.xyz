Pulumi AWS provider 버전은 프로그램이 어떤 AWS 리소스 스키마로 동작할지를 정해요. CLI 버전과 플러그인 버전, package.json에 적힌 패키지 버전은 서로 다를 수 있어요. 운영 스택에서 버전을 바로 올리면 미리보기에서 교체가 나올 수 있어요. 아래는 어디를 보고, 어떻게 고정하고, CI에서 맞추는 순서예요.

## 한눈에 보기

언어 패키지 버전, 실제로 다운로드된 플러그인, CLI는 세 축이에요. 스택이 기억한 프로바이더 버전이 코드와 다르면 업 때 플러그인을 다시 받거나 차이로 실패해요. 버전을 올릴 때는 시험 스택의 미리보기가 먼저예요. 레지스트리의 변경 안내를 같이 봐요.

## provider 버전과 CLI 버전의 차이

CLI는 엔진과 명령이고, provider는 AWS API를 리소스로 번역하는 플러그인이에요. CLI를 올려도 provider가 자동으로 같은 수준이 되지는 않아요. 반대로 패키지만 올려도 CLI가 너무 오래되면 호환 문제가 날 수 있어요. 둘 다 팀에서 고정할 위치를 정해요.

## 버전 관리 방식 비교

표는 패키지 매니저 고정, 플러그인 목록, 스택에 기록된 버전을 나눈 거예요. 잠금 파일이 없으면 설치할 때마다 패키지가 달라져요. CI에서 플러그인을 미리 받지 않으면 네트워크 실패가 배포 실패로 보여요. 운영은 사람이 미리보기를 읽은 뒤에만 올려요.

| 방식 | 주로 쓰는 상황 | 확인할 곳 | 주의할 점 |
|---|---|---|---|
| 패키지 의존성 고정 | 일반적인 애플리케이션과 운영 스택 | `package.json`, `requirements.txt`, `go.mod`, 프로젝트 파일 | 잠금 파일도 함께 커밋해요 |
| 플러그인 수동 설치 | CI 이미지, 오프라인 환경, 배포 전 사전 준비 | `pulumi plugin ls` | 코드 의존성과 다른 버전을 설치하지 않아요 |
| 자동 설치에 맡김 | 로컬 실험과 빠른 확인 | `pulumi up` 실행 로그 | 실행 시점에 따라 버전이 달라질 수 있어요 |

## 단계별로 버전 확인하고 고정하기

패키지 파일과 잠금 파일의 aws 패키지 버전을 봐요. 그다음 플러그인 목록 명령으로 설치된 프로바이더 버전을 비교해요. about 명령으로 CLI를 확인하고, 스택 미리보기에서 프로바이더 교체가 있는지 봐요. 맞출 버전은 레지스트리에 있는 릴리스로 고정하고 시험 스택에 먼저 적용해요.

## 상황별 선택

새 프로젝트는 레지스트리의 현재 안정 버전을 잠금 파일로 고정해요. 운영 중인 스택은 기능이 필요할 때만 올리고, 스키마 변경을 미리보기에서 읽어요. 여러 저장소면 버전을 한 문서에 적기보다 각 잠금 파일을 기준으로 해요. CI는 같은 잠금 파일로 설치해요.

## 주의할 점

패키지 버전과 플러그인 버전이 어긋나면 로컬은 되고 CI는 실패할 수 있어요. 자동 최신 설치는 재현을 깨요. 운영 업을 버전 올린 직후 바로 하지 마세요. 자격 증명 문제를 버전 문제로 오해하지 않게 오류 문구를 나눠요.

## 자주 묻는 질문

확인 위치, 불일치, 운영 업그레이드, CI 사전 설치가 반복돼요.

### Pulumi AWS provider 버전은 어디에서 확인하나요?

패키지 매니페스트와 잠금 파일, 플러그인 목록, 레지스트리 페이지를 같이 봐요. 스택이 마지막으로 쓴 버전은 미리보기나 상태 쪽 정보에 남을 수 있어요. CLI 버전은 about으로 따로 봐요.

### package.json의 버전과 설치된 플러그인 버전이 다르면 어떻게 되나요?

언어 패키지가 요구하는 플러그인과 이미 받아 둔 플러그인이 다르면 업 때 다시 받거나 실패해요. 잠금 파일 기준으로 다시 설치하고 플러그인 목록을 맞춰요. CI와 로컬이 같은 잠금 파일을 쓰는지 확인해요.

### 운영 중인 스택의 provider 버전을 바로 올려도 되나요?

바로 올리지 말고 시험 스택에서 미리보기를 봐요. 리소스 교체나 속성 이름 변경이 있으면 운영 반영 전에 계획을 세워요. 롤백할 패키지 버전도 잠금 파일에 남겨요.

### CI에서 플러그인을 미리 설치하려면 어떻게 하나요?

CI 이미지에 CLI와 필요한 플러그인을 받거나, 작업 시작 때 플러그인 설치 명령을 넣어요. 버전을 명시하지 않으면 최신으로 흔들려요. 네트워크가 막힌 러너면 미러나 사전 포함된 이미지를 검토해요.
