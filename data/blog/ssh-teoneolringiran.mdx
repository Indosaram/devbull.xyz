SSH 터널링은 암호화된 SSH 연결 위에 포트 전달을 얹어, 직접 열기 어려운 서비스에 닿게 하는 방법이에요. VPN처럼 모든 트래픽을 바꾸지는 않고, 지정한 포트나 프록시만 경유해요. 로컬, 원격, 동적 중 누가 포트를 듣는지를 먼저 정하면 설정이 헷갈리지 않아요. 아래는 세 방식의 설정과 끊겼을 때 확인 순서예요.

## 한눈에 보기

터널의 실체는 SSH 세션이에요. 세션이 끊기면 포워딩도 끊겨요. 로컬 포워딩은 내 컴퓨터가 듣고 SSH 서버가 대상에 접속하고, 원격은 반대예요. 동적은 내 컴퓨터의 한 포트를 SOCKS 프록시로 만들어요. 서버가 포워딩을 금지하면 클라이언트 설정만으로는 안 열려요.

## 로컬·원격·동적 포워딩 비교

표는 옵션, 듣는 위치, 대표 용도를 나눈 거예요. 데이터베이스처럼 대상이 하나면 로컬이 맞아요. 외부에서 내 개발 머신을 잠깐 보려면 원격이고, 여러 내부 호스트를 보려면 동적이에요. 방향을 바꾸면 열어야 할 방화벽과 서버 설정도 바뀌어요.

| 구분 | 트래픽이 시작되는 곳 | 대표 옵션 | 주 사용 상황 | 운영 시 유의점 |
| --- | --- | --- | --- | --- |
| 로컬 포워딩 | 내 작업 환경의 로컬 포트 | `-L` | 원격 내부의 데이터베이스나 웹 서비스에 접근 | 로컬 포트 충돌, 대상 호스트 제한, 바인딩 주소 확인 |
| 원격 포워딩 | SSH 서버 쪽의 원격 포트 | `-R` | 원격 환경에서 내 쪽 개발 서비스나 내부 서비스로 접근 | SSH 서버의 포워딩 정책, 방화벽, 접근 제어 확인 |
| 동적 포워딩 | 내 작업 환경의 로컬 SOCKS 프록시 | `-D` | 여러 대상에 임시 프록시가 필요할 때 | 애플리케이션 프록시 설정, DNS 동작, 정책 준수 확인 |

## 단계별 설정 방법

대상이 어디 있는지를 정한 뒤, 비어 있는 포트를 고르고, 세션이 유지되는지 확인해요.

### 로컬 포워딩 설정

내 포트와, SSH 서버가 보는 대상 호스트와 포트를 로컬 포워딩으로 넣어요. 대상 이름의 localhost는 SSH 서버 기준이에요. 내 PC에서 그 포트로 접속해 서비스 응답을 확인해요. 포트가 이미 쓰이면 다른 포트를 골라요.

### 원격 포워딩 설정

서버가 들을 포트와 내 쪽 서비스를 원격 포워딩으로 연결해요. 다른 장비에서 들어오게 하려면 서버의 게이트웨이 관련 허용이 필요해요. 필요하지 않으면 루프백에만 묶어요. 끝나면 세션을 닫아 노출을 끊어요.

### 동적 포워딩 설정

내 포트만 지정하면 SOCKS 프록시가 돼요. 브라우저나 도구가 그 프록시를 쓰도록 설정해야 트래픽이 들어가요. 프록시를 모르는 프로그램은 직접 나가요. VPN과 같다고 안내하지 마세요.

### 연결 유지와 확인

포그라운드에서 오류를 본 뒤, 필요하면 명령 없이 세션만 유지하는 옵션으로 내려요. 끊김은 SSH 세션 종료와 같이 와요. 서버 측 유휴 제한이 있으면 클라이언트 유지 옵션을 문서 기준으로 맞춰요. 자동 재연결이 기본은 아니에요.

## 상황별 선택 기준

관리용 단일 포트는 로컬 포워딩과 설정 파일 별칭이 맞아요. 짧은 데모만 원격 포워딩으로 열고 즉시 닫아요. 여러 호스트를 같은 경유로 보면 동적 포워딩이에요. 상시 경로가 필요하면 터널 대신 정식 접근 정책을 검토해요.

## 주의할 점

터널 포트는 그 머신의 다른 프로세스도 쓸 수 있어요. 원격 포워딩을 모든 주소에 열면 노출이 커져요. 호스트 키 확인을 끄지 마세요. 운영 서버의 포워딩 허용은 변경 관리로 다루고, 개인 편의를 위해 완화하지 않아요.

## 자주 묻는 질문

VPN과의 차이, 끊김 확인, 운영 서버에서의 사용을 자주 물어요.

### SSH 터널링과 VPN은 무엇이 다른가요?

터널은 SSH 세션이 살아있는 동안 지정한 포트나 프록시만 경유해요. VPN은 보통 라우팅 자체를 바꿔요. 프록시 설정이 없는 앱은 터널을 타지 않아요.

### 터널이 끊기면 어떻게 확인하나요?

SSH 세션이 아직 있는지, 로컬 포트가 듣는지, 서버 로그에 연결 종료가 있는지를 봐요. 대상 서비스가 죽은 것과 터널이 죽은 것은 달라요. 재연결은 기본 제공이 아니라서 필요하면 별도 수단을 검토해요.

### 운영 서버에서 원격 포워딩을 써도 되나요?

임시 점검이 아니면 권하지 않아요. 서버 설정을 완화하면 노출이 커지고, 누가 열었는지 추적이 어려워요. 배스천이나 정식 접근 경로가 있으면 그쪽으로 가세요.
